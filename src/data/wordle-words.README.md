# Wordle 词库

`wordle-words.json` 将 `answers`（按长度划分的常用答案）与 `allowed`（允许提交的猜测）分开。答案由项目维护，所有答案必须同时包含在猜测词库中。仅支持小写 ASCII 字母和 4、5、6、7 字母长度；不联网查词。

猜测词库来自开发机 macOS `/usr/share/dict/web2` 快照，筛选原始条目中符合 `^[a-z]{4,7}$` 的词，再合并所有答案及补充的常用复数、过去式和进行式，去重并排序。保留原始大小写后筛选，以排除以大写开头的专名；词库可能包含旧词、技术词及不常用词，因此不直接作为随机答案池。该来源不包含所有现代词形，后续可按需补充。

来源文件 SHA-256：`be41ad97963bf8dabedd5871d5d691596175269d540956b0f9965a885c2bbab9`。系统附带说明将其标为 Webster's Second International 词表，称其 1934 年版权已到期，并记录 FreeBSD 对拼写的维护。导入日期：2026-10-20。

修改后运行 `node scripts/check-wordle.mjs`，验证答案长度、唯一性、猜测词覆盖、随机抽取和重复字母规则。数据独立存放，不在游戏逻辑中维护长单词字符串。
